# Personal Portfolio & Engineering Showcase

Welcome to the source code of my personal portfolio website. This platform serves as a modern, high-performance digital hub designed to showcase my full-stack web development capabilities, interactive design experiments, and engineering philosophy to global clients and collaborators.

## 🔗 Live Deployment
* **Production URL:** [https://devfaisalkhan.vercel.app/](https://devfaisalkhan.vercel.app/)

## ✨ Design Philosophy & Core Features
* **Premium Minimalist Aesthetic:** Engineered with a clean, highly polished neutral dark theme focusing on flawless alignment, typography, and layout spacing.
* **Bento Grid Architecture:** Utilises a highly responsive, modern grid layout to compartmentalise projects, skills, and professional experience elegantly across all device screen sizes.
* **Interactive Elements:** Features fluid transitions, micro-interactions, and optimised performance to maintain a pristine user experience.
* **Client-Focused Case Studies:** Integrated deep dives into featured projects (like AuraSaaS and MoodFlix), highlighting problem-solving and direct business value.

## 🛠️ Built With
* **Frontend:** HTML5, CSS3, JavaScript (ES6+) 
* **Hosting & CI/CD:** Vercel via GitHub Automation
* **Performance Tuning:** Optimized asset delivery, ensuring a 95+ Google Lighthouse score for speed and accessibility.

## 💻 Running the Project Locally

If you wish to explore or test the codebase locally:

1. Clone or download this repository.
2. Open the project folder in your favourite code editor (e.g., VS Code).
3. If running a static setup, simply open `index.html` in your browser, or spin up a local development server using an extension like **Live Server**.
